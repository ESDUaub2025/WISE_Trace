# Local automated evidence

These results describe a working implementation milestone, not completion of the entire PRD or production approval.

On 2026-10-06:

- TypeScript and ESLint passed.
- Vitest: 31 tests passed, including atomic media rollback, outbox save order, interrupted sync recovery, conflict retention, user partitioning, PIN verification, sealed receiving credentials, signature binding, session limits and recurring stage schedules.
- pgTAP: 157 checks passed against local PostgreSQL. Checks include cooperative isolation, denied raw donor reads, anonymous RPC grants, append-only audit/ledger records, prohibited state transitions, allocation and sales limits, training content/schema and cooperative scope, SOP-triggered refreshers, completion expiry/task closure, measurement attribution/unit/equipment boundaries, owner bootstrap, offline signature tampering/device/expiry boundaries, server-derived late-entry flags, handover, abandonment losses, equipment checks and impact role boundaries.
- Playwright preview: 16 checks passed on desktop Chromium and Pixel 7, including offline reload, Arabic RTL, receipt declaration reuse and a public page without React.
- Playwright live: twelve scenarios (eleven in the full suite and the new notification scenario separately) passed against local Supabase Auth, database, private Storage and Edge sync. A1 checks threshold suggestions and override deviations; A2 checks offline persistence and an allocation conflict; A3 checks photo retention with a simulated OCR provider response; A4 checks a critical release blocker and an independent supervisor's PIN release; A5 traces from whey through stock and sales, closes a mock recall, then checks a live public recall notice; A6 checks neutral/released public data in both languages; A7 checks donor suppression and indicator definitions. The eighth scenario rejects an incorrect PIN, accepts whey provisionally on the receiving device, reloads offline, confirms that PIN/plaintext secret are absent from the outbox, and synchronizes the signed decision. The ninth scenario uses actual TOTP enrollment and AAL2 admin login, compresses a real picture and one-second synthetic video, uploads to private Storage, denies anonymous access, publishes a resource-backed module, and verifies producer downloads after an offline reload.
- Added material-balance, yield and impact checks cover residual closure rollback, recorded diversion destinations, packaging yield justification, zero denominators, test-data exclusions and metric units. Label unit tests check required approved fields and the thermal raster header; live label downloads check A4 dimensions and multi-page copy counts in both languages. Offline material disposition survives a reload and reconciles after sync.
- The notification scenario confirms persisted consent, ignores caller-provided destinations/consent, queues a personal acknowledgment offline, reloads it, syncs it, and denies delivery after withdrawal.
- A clean local database reset applied migrations and loaded the fictional seed. All migrations through 202610060059 applied in the latest clean reset.
- `node scripts/live-api-check.mjs` passed the authenticated production/packaging/release/sale/mock/live recall workflow.
- `node scripts/check-reports.mjs` passed CSV, Excel and PDF exports through the actual Edge function, date/material filtering and traceability history reconstruction. PDF size depends on the selected dataset; Arabic and Latin glyph availability is checked separately. Full font embedding avoids a fontkit subset encoder failure found by the live test.

The browser scenarios correspond to A1–A7 but do not yet prove every bullet in those stories. Rejected receipts on a second device, scheduled home-screen drying checks, a producer with both production and release roles, and an actual Food-Safety Lead MFA session need additional browser coverage. Real OCR inference is untested without an Anthropic secret. Hosted latency, actual phone storage pressure, thermal printer behavior, SMS/WhatsApp delivery, backups and restore drills are not demonstrated by these local checks.

Run local live tests with `npm run db:start`, `node scripts/setup-local.mjs`, and `npx supabase functions serve` in a separate terminal, then `npm run test:api` and `npm run test:live`. Port 5173 must be free; the suite serves a production PWA build there. Preview tests use port 4173 and explicitly fictional UI data.
